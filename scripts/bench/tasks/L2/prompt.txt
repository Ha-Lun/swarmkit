In the user service in svc/, add POST /users/import. The body is {"users": [{"name": ..., "email": ...}, ...]}. It is all-or-nothing: if anything is wrong with any entry, nothing is created. Each entry is validated like POST /users. An email may not already exist in the service and may not appear twice in the batch, ignoring capitalisation. Validation errors return 400 with {"errors": [{"index": i, "errors": [...]}]}; duplicate emails return 409 with {"errors": [{"index": i, "error": "email already registered"}]} (index of the later entry). At most 100 users per request: more is 413. A missing, empty or non-list `users`, or an entry that is not an object, is 400. On success return 201 with {"users": [...]} in input order. Update docs/API.md and add tests.
