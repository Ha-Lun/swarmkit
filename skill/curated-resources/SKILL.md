# Curated Resources Skill

This skill contains reference guides and usage patterns for the 16 curated developer, design, scraping, and MCP resources.

## Scraping & APIs
- **scrapeling** (github.com/D4Vinci/Scrapeling): Stealth python scraping patterns. It provides anti-detection mechanisms, proxy rotation, and headless browser orchestration for robust data extraction.
- **public-apis** (github.com/public-apis/public-apis): A collaborative, domain-indexed catalog of free APIs. Useful for mocking data or integrating third-party services without immediate financial overhead.

## Infrastructure & Compute
- **free-for-dev** (github.com/ripienaar/free-for-dev): Comprehensive directory of software (SaaS, PaaS, IaaS, etc.) with free tiers for developers. Covers cloud computing, databases, CI/CD, and authentication.

## Agents & Automation
- **OpenHands** (github.com/All-Hands-AI/OpenHands): Framework for agent sandbox execution. Highlights self-healing loop design patterns and secure agent-environment interactions.

## General Knowledge & MCP
- **awesome** (github.com/sindresorhus/awesome): The canonical index of awesome lists, spanning all languages and ecosystems.
- **awesome-mcp-servers** (github.com/punkpeye/awesome-mcp-servers): A curated list of Model Context Protocol (MCP) servers, enabling diverse integrations for AI agents.
